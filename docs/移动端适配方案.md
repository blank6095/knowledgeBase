## 2. 断点定义

| 断点 | 范围 | 布局策略 |
|---|---|---|
| 桌面 | `≥ 1024px` | 三栏 / 双栏；详情为右侧空间浮层 |
| 平板 | `768 – 1023px` | 双栏收为单主栏 + 可收起侧栏；详情浮层宽度 ≤ 420px |
| **移动** | `< 768px` | 单列；详情为**底部 sheet**；导航固定底部；图谱全屏画布 |
| 窄屏 | `< 360px`（含 320） | 再收一档：卡片内边距 12、字号不降级、按钮换行、隐藏非必要装饰 |

**视口目标**：320×720、375×667、390×844（对应执行版 §4 四视口口径中的三个移动档）。

**统一硬指标**：

1. `document.documentElement.scrollWidth ≤ clientWidth`（**无横向溢出**）。
2. 所有可点元素 **≥44×44px**，相邻间距 ≥8px。
3. 底部导航固定占位由 `padding-bottom: calc(72px + env(safe-area-inset-bottom, 0px))` 补偿，**不得压盖页脚或悬浮按钮**。
4. 正文 ≥16px、行高 ≥1.6、行宽 ≤ 70ch；正文字号**不因窄屏降级**。

## 3. 方案一 · 图谱触控

| 交互 | 桌面 | 移动端（独立设计） |
|---|---|---|
| 平移 | 拖拽画布 | 单指拖拽；`touch-action: none` 只作用于画布容器，页面其余区域仍可滚动 |
| 缩放 | 滚轮 / 按钮 | 双指捏合；另提供 **≥44px** 的 `+` / `−` 按钮作为可达替代 |
| 选中节点 | 单击 | **tap**；命中容差扩展到 44px 的隐形热区，避免指尖遮挡 |
| 查看关联 / 更多 | 右键菜单 | **长按 ≥400ms** 或详情浮层内的「查看完整关系」按钮；不依赖 hover |
| 双节点路径 | 修饰键多选 | 进入「路径探索」模式后**依次 tap 两个节点**，顶部给出进度提示「请选择起点 / 终点」 |
| 搜索 | 顶部输入框 / `Ctrl+K` | 顶部常驻 **≥44px** 搜索按钮，点击展开全宽输入层；不做桌面框的等比缩小 |
| 视角还原 | 记录位置 | 进入学习 / AI 前保存「离开前的图谱位置」，返回时还原（两层状态模型第二层上下文） |

**约束**：移动端图谱不出现 hover 专属信息；节点标签在窄屏默认只显示当前选中项及其邻近节点，避免满屏文字。

## 4. 方案二 · 面板展开

| 项 | 规则 |
|---|---|
| 形态 | 移动端详情 / AI 面板为**底部 sheet**，桌面为空间浮层（不遮挡主操作） |
| 高度 | 三档：收起（仅标题条 56px）／半屏（约 55vh）／全屏（约 92vh）；拖拽把手 **≥44px** |
| 打开 | 焦点移入面板；`aria-modal` 生效；背景画布置为 `inert` |
| 关闭 | 拖拽下滑、点遮罩空白、`Esc`、关闭按钮（**≥44px**）四选一；关闭后焦点归还触发元素 |
| 不遮挡 | sheet 半屏时，图谱主操作区（搜索 / 缩放 / 模式切换）保留在 sheet 上方可见区域；全屏时提供明确的「返回图谱」按钮 |
| 安全区 | `padding-bottom: env(safe-area-inset-bottom, 0px)`；sheet 底部操作条不与系统手势条重叠 |
| 滚动 | sheet 内部独立滚动，禁止body 穿透滚动 |

## 5. 方案三 · 导航

| 项 | 规则 |
|---|---|
| 结构 | 底部固定栏 **3 个核心入口 + 「更多」抽屉**，沿用现有 `compactOnMobile`（已核实） |
| 尺寸 | 每项宽度由 `li` 均分，但 **最小宽度 ≥44px**；320px 下 4 项 × 44px = 176px，仍有余量 |
| 抽屉 | 「更多」展开为底部抽屉，含其余入口与退出登录；抽屉项高 ≥48px |
| 悬浮元素 | 目录 / 回到顶部等悬浮按钮 `bottom ≥ 72px + safe-area`，**不得与底栏重叠** |
| 页脚 | 内容区底部留白 ≥ `72px + safe-area`，避免文字被压盖 |
| 全局检索 | 移动端提供独立触控入口（现状 `AppShell.tsx:91` 已有），不依赖 `Ctrl+K` |

## 6. 方案四 · 阅读布局

| 项 | 规则 |
|---|---|
| 结构 | 桌面「左正文 / 右关系与记忆」→ 移动**单列**：正文在前，关系与记忆折叠为可展开区块 |
| 正文 | `--ku-font-reading`、`16px`、`line-height 1.6+`、行宽 ≤70ch、偏暖高对比（`#ECE6DA` on `#11182A`，14.22:1） |
| 顶部 | 返回图谱按钮 **≥44px**，常驻 sticky；所属社区作为文字，不占一行按钮 |
| 底部操作 | 阅读 / 编辑 / 复习 / 询问 AI 四项在窄屏 **2×2 折行**，每项 ≥44px，不挤压成一行 |
| 目录 | 悬浮目录按钮上移到 `bottom ≥ 72px + safe-area`，与底栏不重叠 |
| 三态 | 空 / 加载 / 错误态在移动端有独立画面，不使用桌面缩略图 |

## 7. 与方向文档 §7 首轮清单第 5 项的对照

> 第 5 项：「移动端是否有独立合理的交互，而不是桌面版缩小？」

| 检查点 | 本方案 | 原型中的可验证位置 |
|---|---|---|
| 导航不是桌面缩小 | 3 核心 + 更多抽屉，而非 8 项平铺 | 三页底部导航 |
| 面板不是抽屉缩小 | 底部 sheet 三档高度 + 拖拽把手 | 图谱详情浮层 / AI 浮层 |
| 图谱触控独立 | tap 容差、长按、双指缩放 + 按钮替代、依次 tap 选路径 | 图谱页模式切换与节点交互 |
| 阅读布局独立 | 单列、关系折叠、操作 2×2 折行 | 知识详情页 |
| 悬浮元素不遮挡 | 目录按钮上移、页脚留白 | 四视口几何核对 |
