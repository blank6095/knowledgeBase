## 1. 现状基线（已核实，决定任务边界）

### 1.1 已有可直接复用的能力

| 能力 | 位置 | 复用方式 |
|---|---|---|
| 力导向 Canvas + `nodeCanvasObject` 自定义绘制 | `src/app/graph/page.tsx`（861 行单文件） | 保留绘制模型，不换引擎（与建议 §八·3 一致） |
| 记忆度着色 / 节点大小=关联数 / 光晕∝记忆度 | `page.tsx` 的 `memoryColor()`、`drawNode()`（半径 `1.6+√degree`，光晕 `2+10×memory`） | **语义保留，不得被皮肤覆盖** |
| 节点 sprite 离屏缓存（色桶×半径×光晕×白热，上限 512，满则整体清空） | `src/app/graph/node-sprites.ts` | 节点风格需扩展缓存键（见 U3-3 风险） |
| warmup 自适应、视口剔除、theta 自适应 | `src/app/graph/mount-utils.ts`（`warmupTicksFor` / `nodeInsideViewport` / `manyBodyThetaFor`） | 主题/搜索切换不得破坏这些路径 |
| 坐标缓存（布局停止后复用初始坐标） | `page.tsx` 的 `positionCache`（约 L116） | 过滤重建 `graphData` 时作为低扰动初始值 |
| 视口聚焦能力 | `react-force-graph-2d@1.29.2` / `force-graph` 已提供 `centerAt(x,y,durationMs)`、`zoom(scale,durationMs)` | U2-4 仅需扩展 `FGInstance` 类型声明（当前类型只有 `pauseAnimation/resumeAnimation/d3Force/d3ReheatSimulation`） |
| 知识点详情数据（content / headingPath / tags / summary / 邻居） | `GET /api/segments/[id]` | U1-5 详情面板**无需新增接口** |
| 双节点 AI 关联解释 | `/api/ai/connect` + 页面 `compareMode` | U4-2 在其上叠加路径高亮 |
| 今日学习 / 薄弱 / 到期复习数据 | `/api/learning/today`（reasonCode 含 `due-review`、`previous-incorrect` 等）、`/api/stats`（byTier / weakTop3） | U4-3 学习地图的数据源已具备 |
| 表现层基础（对比度 / 浮层碰撞 / 主题色出口） | `src/lib/ui/contrast.ts`、`src/lib/ui/geometry.ts`（`clampPopover`）、`src/lib/ui/theme.ts`（`PALETTE`） | 浮层与反馈优先复用，不重复造 |
| 反馈与错误态组件 | `src/components/InlineFeedback.tsx`、`src/components/ErrorState.tsx` | 面板/搜索的加载、空、错误态复用 |
| 压测入口 | `/graph?fixture=`（可选 `graph-small` / `graph-mid` / `graph-large`，当前文件 500 / 5000 / 8000 节点）+ `scripts/gen-graph-data.mjs` + `npm run perf:graph`（`scripts/measure-graph.mjs`，输出 `artifacts/graph-baseline.json`） | 每阶段出口必须跑三档回归（基线口径见 §12 注） |

### 1.2 与建议之间的具体缺口

| 建议要求 | 现状 | 缺口 |
|---|---|---|
| 图谱为登录首屏 | `/` 是概览（今日学习主入口，F1 已完成），`/graph` 为独立页 | 需产品决策（UQ1/UQ3） |
| 左侧悬浮窄导航 | `AppShell.tsx` 固定 15rem 侧边栏（5 个入口 + 设置/退出；底部另有全站 footer） | 需新建，且需确认是否全站替换（UQ2） |
| 顶部悬浮搜索（Ctrl+K） | 搜索仅在图谱页「设置面板」的「筛选」tab，仅 `title.includes()`，无结果列表/无聚焦 | U2 全组 |
| 单击选中 / 双击进入 | **单击直接 `router.push('/segments/[id]')`**（`compareMode` 下改为选中） | 属破坏性交互变更（U1-6） |
| 搜索索引标题+标签+摘要 | `/api/graph` 节点仅 `id/title/memory/viewCount/readingMs/documentTitle` | 需扩载荷或另开索引源（U0-2，UQ4/UQ5） |
| 背景分层 | 画布背景由 `backgroundColor={CANVAS.bg}` 写死 `#0f0d0b` | U0-3 |
| 主题/节点风格集中管理 | 画布色值散落在 `page.tsx` 的 `CANVAS`/`KINDS` 常量 | U3-1 |
