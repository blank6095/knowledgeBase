## 1. 环境变量全表

配置文件：本地 `.env.local`（`npm run db:migrate` 通过 `--env-file=.env.local` 读取）；生产环境在 Vercel 项目设置中配置。

### 1.1 必填

| 变量 | 作用 | 缺失后果 | 代码位置 |
|---|---|---|---|
| `DATABASE_URL` | Neon Pooled 连接串 | 数据库惰性初始化抛错；构建期也会失败（路由模块导入即校验） | `src/db/index.ts:11` |
| `AUTH_PASSCODE` | 全站单口令 | 认证网关 fail-closed：页面重定向登录、API 401/503 | `src/proxy.ts:13`、`src/lib/auth.ts:4` |

### 1.2 可选：加密与存储

| 变量 | 作用 | 默认行为 | 代码位置 |
|---|---|---|---|
| `SETTINGS_ENCRYPTION_KEY` | 加密 `app_settings` 中 LLM API Key 的主密钥 | 未填时回退到 `AUTH_PASSCODE` 派生 | `src/lib/secret-crypto.ts:3` |
| `R2_ACCOUNT_ID` / `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` / `R2_BUCKET` | 导入时备份原文 md | 任一缺失则跳过备份，导入照常可用 | `src/lib/r2.ts` |

### 1.3 可选：大模型

设置页配置优先于环境变量；环境变量仅作回退。

| 组合 | 生效条件 | 说明 |
|---|---|---|
| `LLM_API_KEY` + `LLM_MODEL` | 二者同时存在 | 最完整的回退组合 |
| `DEEPSEEK_API_KEY` | 只给 Key 即可 | 模型缺省 `deepseek-v4-flash`，可用 `DEEPSEEK_MODEL` 覆盖 |
| 应用内「设置」页 API Key + 模型 | DB 有值 | 推荐方式，即存即用，无需重启 |

- Base URL 固定为 `https://api.deepseek.com`（OpenAI 兼容），改动需改 `src/lib/llm.ts:20`。
- 默认模型常量 `DEFAULT_MODEL = 'deepseek-v4-flash'`（`src/lib/llm.ts:25`）。
- 未配置时前端拿到的提示文案来自 `LLM_SETUP_HINT`；数据库读失败且无回退时区分提示 `LLM_DB_DOWN_HINT`（`src/lib/llm.ts:83-87`）。

### 1.4 示例

```ini
# 必填
DATABASE_URL=postgresql://user:pass@ep-xxx-pooler.xx.aws.neon.tech/neondb?sslmode=require
AUTH_PASSCODE=change-me-to-a-long-random-string

# 可选：独立主密钥（推荐生产使用，避免改口令导致旧密文失效）
SETTINGS_ENCRYPTION_KEY=

# 可选：R2 原文备份
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=

# 可选：LLM 回退
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=
# 或
LLM_API_KEY=
LLM_MODEL=
```

## 2. 认证与访问控制

### 2.1 会话机制

| 项 | 值 | 代码位置 |
|---|---|---|
| Cookie 名 | `kb_session` | `src/lib/auth.ts:1` |
| 令牌算法 | `sha256("kb-v1:" + AUTH_PASSCODE)` | `src/lib/auth.ts:13-21` |
| Cookie 属性 | HttpOnly；有效期 30 天 | `src/lib/auth.ts:2` |
| 网关 | `src/proxy.ts` 全站拦截 | `/login`、`/api/auth/*` 放行 |
| 二次校验 | 路由内 `guard()` | `src/lib/api.ts` |
| 登录后跳转 | `safeNextPath()`，默认 `/graph` | `src/lib/security.ts:14-24` |

> 设计取舍：令牌不加盐、不落库，泄露面等价于口令本身；适合个人自用，不适合多用户场景。

### 2.2 登录限流

- 窗口 10 分钟，同一来源失败 5 次即拒绝，返回 `retryAfterSec`。
- 来源取 `x-forwarded-for` 首段或 `x-real-ip`，缺失时归为 `unknown`。
- 进程内实现（`src/lib/login-rate-limit.ts`），多实例下不共享；上限 1000 个 key 自动淘汰。

### 2.3 安全响应头

`next.config.ts` 已配置 `X-Frame-Options: DENY`、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy` 与强制 CSP。修改外链来源（如图片域名）时需同步调整 CSP，否则会被拦截。

## 3. 大模型配置（设置页）

路径 `/settings`，入口 `src/app/settings/page.tsx`。

| 字段 | 说明 | 存储 |
|---|---|---|
| API Key | 只回显尾号（`keyTail`），留空表示不修改 | `app_settings.key='llm'`，AES-GCM 密文 |
| 主模型 | 默认/复杂任务使用的模型 id | `app_settings` JSON |
| fast 模型 | 摘要、测试连接等轻任务；留空则与主模型同档 | `app_settings` JSON |
| 学习者自述 | 参与画像与回答风格，注入 prompt | `app_settings.key='learner'` |

加密细节（`src/lib/secret-crypto.ts`）：

- 算法 AES-GCM，随机 12 字节 IV，密文格式 `enc:v1:<iv>:<cipher>`。
- 密钥 = `SHA-256("kb-settings-v1:" + masterSecret)`，`masterSecret` 取 `SETTINGS_ENCRYPTION_KEY`，否则取 `AUTH_PASSCODE`。
- **改口令或换主密钥会导致旧密文无法解密**，需要在设置页重新填写 API Key。
- 旧明文值首次读取时按原样返回，保存时自动转为密文。

调用护栏（`src/lib/llm.ts`、`src/lib/llm-calls.ts`）：

| 机制 | 值 |
|---|---|
| 单次超时 | 60s（整流），流式 chunk 静默 30s |
| 默认 `max_tokens` | 2048（拆解类建议 4096） |
| 重试 | 429 / 5xx / 网络错误指数退避 1 次，其余 4xx 不重试 |
| 并发 | 进程内信号量 ≤3，超出排队 |
| 日 token 护栏 | 超限拒绝调用（`assertDailyTokenBudget`） |
| 可观测 | 每次调用写 `llm_calls`（kind/model/token/耗时/错误；不含 prompt） |
| 输出缓存 | `llm_cache` 表，256 条上限；ask 直答 24h TTL |

## 4. 对象存储（R2）

- 用途：导入时备份原始 markdown，键记录在 `documents.storageKey`。
- 不配置时导入链路完整可用，只是不备份。
- 控制台创建桶后，创建 `Object Storage: Edit` 权限的 API Token，填 4 个变量。
- 已知限制：附件/图片上传仍未实现（Roadmap 项）。

## 5. 缓存与降级

| 层 | 实现 | 失效方式 | 适用 |
|---|---|---|---|
| 进程内 TTL | `src/lib/cache.ts` | 写操作后主动失效 | stats / notes / graph / learning 等读接口 |
| 陈旧快照 | `src/lib/cache.ts` + `src/lib/db-read.ts` | 到期后仍保留为降级数据 | 数据库抖动时返回旧值，响应头 `X-Cache: STALE` |
| 数据库 LLM 缓存 | `llm_cache` 表 | 过期判定 + `onConflictDoUpdate` 覆盖 | AI preview / ask 直答 |
| 客户端图谱偏好 | `localStorage` | 用户在主题/力面板修改 | 图谱外观、力参数、筛选偏好 |

约束：进程内缓存为单实例 best-effort；Vercel 多实例部署下写后失效只作用于当前实例，允许短窗口内不一致。

## 6. 图谱配置

### 6.1 数据源切换

| 方式 | URL | 数据来源 |
|---|---|---|
| 真实数据 | `/graph` | `GET /api/graph`（节点 = 知识点，记忆度读取时现算） |
| 压测数据 | `/graph?fixture=graph-small` | `public/fixtures/graph-small.json` |
| 压测数据 | `/graph?fixture=graph-mid` | `public/fixtures/graph-mid.json` |
| 压测数据 | `/graph?fixture=graph-large` | `public/fixtures/graph-large.json` |

fixture 文件不入库、被 `.gitignore` 忽略，需用 `node scripts/gen-graph-data.mjs` 生成；进入压测模式时顶栏显示徽标。

### 6.2 客户端偏好

| 偏好 | 存储键 | 默认 |
|---|---|---|
| 主题（环境 × 风格） | `graph-preferences`（localStorage） | 暖色 / 默认风格 |
| 力参数（电荷、距离、碰撞等） | 同上 | 内置默认值 |
| 显示项（标签、箭头、小地图等） | 同上 | 小地图默认关闭 |

偏好只存在浏览器本地，不写数据库、不跨设备同步。

### 6.3 性能开关

- 8k 节点以上才需要考虑社区聚合或 WebGL（当前未实现，见 [未完成任务清单.md](./未完成任务清单.md) D2）。
- 小地图默认关闭，开启后为 168×112 缩略图，点击/拖动触发 `centerAt`，不发请求、不重排。
- 压测命令：`npm run perf:graph`。

## 7. 配置自检清单

1. `DATABASE_URL` 是否为 Pooled 连接串，带 `sslmode=require`。
2. `AUTH_PASSCODE` 是否足够长；是否与团队共享过（决定是否需要换）。
3. 是否设置了独立 `SETTINGS_ENCRYPTION_KEY`；若改过口令，设置页的 Key 是否仍能测试连接通过。
4. LLM 是否已配置：`/api/ai/config` 返回 `configured: true`。
5. R2 四个变量是否齐全；不齐全时导入页面仍可用，属预期。
6. `public/fixtures/` 是否存在所需档位（仅压测需要）。
