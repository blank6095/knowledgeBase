## 2. 视觉通道唯一语义表（执行版 §4 原文落实）

| 视觉属性 | 只表达什么 | 不得用于 | 数据来源 |
|---|---|---|---|
| 节点**亮度** | 记忆新鲜度 | 搜索匹配程度、选中状态 | `/api/graph` 的 `nodes[].memory`（T01 §4.4 已核实） |
| 节点**透明度 / 饱和度** | 搜索匹配程度 | 记忆状态、掌握结论 | 前端搜索结果，无后端字段 |
| 节点**外环** | 存在真实学习记录证据 | 待复习、选中 | `latestResult`（间接、非全图谱；DEC-01 待评审） |
| **橙色标记** | 待复习状态 | 记忆亮度、搜索命中 | `reasonCode` / `nextReviewAt`（仅今日推荐条目；DEC-01 待评审） |
| **双层光环** | 当前选中状态 | 业务状态 | 交互状态，无数据字段 |
| **关系线强调** | 当前搜索或路径上下文 | 记忆状态 | 前端交互状态 |

> **硬规则（v1.2）**：搜索聚焦**不得覆盖记忆亮度**；非匹配节点只用透明度 / 饱和度降权。一个记忆新鲜度高但未命中搜索的节点，亮度必须保持不变。

### 2.1 §6 表 5 · 状态语义表（T02 交付，解决 A7 的结构基础）

| 维度 | 表达什么 | 视觉方式 | 数据来源 | 与现有实现的关系 |
|---|---|---|---|---|
| 记忆新鲜度 | 多久没有被有效回顾 | 节点**亮度** | `/api/graph` 的 `nodes[].memory` | 沿用现有记忆档位表达，不被皮肤覆盖 |
| 搜索匹配程度 | 当前搜索命中与否 | 节点**透明度 / 饱和度** | 前端搜索结果，无后端字段 | **独立通道，不占用亮度** |
| 复习状态 | 是否到了应复习时间 | **橙色提示标记** | `/api/learning/today` 的 `reasonCode` / `nextReviewAt`（仅今日推荐条目） | 独立于亮度，不与记忆新鲜度共用通道 |
| 掌握证据 | 是否存在真实学习记录 | **青色外环** | `latestResult`（间接、非全图谱） | **无可靠字段时不显示**；不得称「已掌握」 |
| 选中状态 | 当前交互焦点 | 双层光环（交互态） | 交互状态，无数据字段 | **不是业务状态**，不与上述四者冲突 |

> **T09 视觉编码优先级**：亮度（记忆）→ 透明度（搜索）→ 外环（学习记录证据）→ 提示标记（复习）→ 光环（交互选中）。同一节点可叠加表达，但**每个通道只写一个视觉属性**。

## 3. A7 色彩口径 · 评审输入（待确认，不代签）

**问题**：新色板（探索蓝 / 智能紫 / 掌握青 / 待复习橙）与现有实现中的**琥珀记忆档位灯色**如何共处，避免同一节点出现两种「都在说记忆」的颜色。

| 备选 | 含义 | 影响 |
|---|---|---|
| ① 并存 | 两套颜色各自出现，不做约束 | 同一节点可能既有琥珀灯又有新语义色，语义混淆，不推荐 |
| ② 替换 | 用新色板完全替换现有琥珀档位 | 需改 `memoryColor` 语义计算，触碰执行版全局禁止范围，不推荐 |
| ③ **分层（建议口径）** | **记忆档位只走亮度连续量**（现有档位映射为亮度档，不新增色相）；**色相只承担离散语义**（探索 / AI / 学习记录 / 待复习 / 选中）。两类信息不同层，不抢同一通道 | 不改 `memoryColor` 的语义计算；符合 §2 唯一语义表；T09 只需把档位映射为亮度值 |

> **建议采用 ③ 分层**，但这是**评审输入**，最终由 T02 评审记录确认并归档；本文件不把建议写成结论。评审记录位置：[T07评审材料.md](./T07评审材料.md) §3。

## 4. 字体、间距与层级

| 项 | 规范 |
|---|---|
| 字体 | UI：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；正文阅读：`Georgia, "Songti SC", "SimSun", serif` 或同族偏暖衬线，**仅 T06 知识详情正文使用** |
| 字号 | 桌面 UI 13 / 14 / 16 / 20 / 28；正文 **17px**、行高 **1.75**；移动端正文 **16px** 起，不得低于 16px |
| 行宽 | 正文单列 **60–70ch**（约 640–720px），超过即用留白收窄，不得拉伸到全宽 |
| 间距 | 4px 基准：`4 / 8 / 12 / 16 / 24 / 32 / 48`；卡片内边距 16（移动 12）；区块间距 24（移动 16） |
| 圆角 | 卡片 12px、按钮 8px、胶囊 999px、浮层 16px |
| 层级 | 画布 0 → 背景层 10 → 关系线 20 → 节点 30 → 标签 40 → 详情浮层 50 → 全局 AI 浮层 60 → 抽屉 / 导航 70 |
| 触控目标 | **≥44×44px**（含图标按钮），相邻目标间距 ≥8px；见 [移动端适配方案.md](./移动端适配方案.md) |

## 5. 节点规范

| 维度 | 规则 |
|---|---|
| 大小 | 只表**关联数**（`sqrt(degree)` 线性映射）或用户主动设置的重要程度之一，**不得混用**；不得用大小表达记忆或掌握 |
| 亮度 | 唯一输入为 `memory`，映射区间 `0.35 ~ 1.0`；函数签名不接收搜索上下文（结构保证） |
| 透明度 | 唯一输入为搜索匹配：命中 `1`，未命中 `0.22`；无查询时 `1` |
| 外环 | 青色 1.5px、半径 `r+4`；**仅在存在真实复习记录时出现**，标注为「有学习记录」而非「已掌握」（DEC-01 待评审） |
| 标记 | 橙色圆点 2.4px、位置 `(r+2, -(r+2))`；只取 `reasonCode` / `nextReviewAt`（DEC-01 待评审） |
| 光环 | 探索蓝双层 `r+5` / `r+9`，仅当前选中节点 |
| 标签 | 默认只展示焦点及邻近重要节点；缩放阈值 `zoom ≥ .55`；单帧上限 45 个；按「选中 > 命中 > 关联度」排序 |
| 三态 | 空数据 / 加载中 / 错误态需有独立画面，不得用空白画布代替 |

> 第一版**不做 3D 模型、不做节点皮肤商城**（执行版 §3 暂缓项）。

## 6. 关系线规范（第一轮 2 种）

| 类型 | 宽度 | 颜色 | 触发 |
|---|---|---|---|
| 普通 | 1px | `--ku-edge` | 默认 |
| 强调 | 1.8px | `--ku-edge-strong` | 搜索双端命中 / 路径上下文 |

- 线型只分普通 / 强调两种；**不实现曲线、能量线、弱化线**（范围已收敛）。
- 未命中搜索的边用透明度降权，**不得调暗节点亮度**。

## 7. 动效规范（第一轮 2 档）

| 档 | 行为 | 约束 |
|---|---|---|
| 静态（默认） | 无逐帧动画；仅选中 / 聚焦的瞬时过渡 ≤160ms | 关闭动效后图谱完全可用 |
| 轻量动态 | 星云背景极缓位移、节点呼吸（单周期 ≥3s） | **无持续高负载动画、无粒子系统、无逐帧粒子计算** |

## 8. 背景规范（与节点皮肤分离，3 套）

| 背景 | 表现 | 默认 |
|---|---|---|
| Deep Space | 纯 `--ku-deep-space` + 极稀星点 | **是** |
| Nebula | 两个静态径向渐变（紫蓝），轻量动态档下极缓位移 | 否 |
| Cosmic Grid | 64px 网格线 `rgba(117,167,255,.07)` | 否 |

## 9. 对比度与可读性规则

1. 正文对比度 ≥ **4.5:1**，大字 / 图形 / 状态标记 ≥ **3:1**（§1.3 实测全部达标）。
2. 语义色不得作为**唯一**信息载体：外环 / 标记必须同时有文字或 `aria-label` 说明。
3. 正文容器不透明度 = 1；禁止在长文区域使用半透明面板。
4. 搜索降权后的节点不得让文字标签对比度低于 3:1；标签在降权节点上默认隐藏。

## 10. 无障碍与键盘交互规则

| 项 | 规则 |
|---|---|
| 焦点 | 所有可交互元素有可见 focus ring（`--ku-explore` 2px，offset 2px）；浮层打开时焦点移入，关闭后归还触发元素 |
| 焦点陷阱 | 详情浮层 / AI 浮层 / 抽屉内焦点循环；`Esc` 关闭并归还焦点 |
| 键盘 | `Enter` / `Space` 选中节点；`↑↓←→` 在邻近节点间移动；`/` 聚焦搜索；`Ctrl/⌘+K` 全局检索；`Esc` 清除搜索或关闭浮层 |
| 语义 | 节点用 `role="button"` + `aria-label`（含标题、记忆档位、是否有学习记录、是否待复习）；关系线为 `aria-hidden` 装饰 |
| 状态播报 | 搜索结果数、模式切换、错误态用 `aria-live="polite"` 播报 |
| 减弱动效 | `prefers-reduced-motion: reduce` 时强制静态档 |
| 触控 | 所有目标 ≥44×44px，详见 T03 |
