## 3. 登录

- 唯一公开页面，只输入访问口令（`AUTH_PASSCODE`），无注册、无第三方登录。
- 登录成功后按 `safeNextPath()` 跳转：合法的站内路径优先，否则默认进 `/graph`（`src/lib/security.ts:14-24`）。
- 连续失败触发限流：10 分钟窗口内 5 次失败后拒绝（`src/lib/login-rate-limit.ts`）。
- Cookie `kb_session` 为 HttpOnly，30 天有效；退出即清除。

## 5. 知识宇宙（`/graph`）

### 5.1 定位

图谱是全站主入口：登录后默认进入，全屏沉浸式，无传统导航栏（改用悬浮窄栏）。

### 5.2 数据与渲染

| 项 | 说明 |
|---|---|
| 数据源 | 默认 `GET /api/graph`；`?fixture=graph-small\|mid\|large` 读取 `public/fixtures/*.json` |
| 图结构 | 节点 = 知识点；边 = `wiki`（双链）/ `tag`（共同标签）/ `doc`（同文档相邻） |
| 节点大小 | 按关联数（degree）缩放 |
| 节点亮度 | 按记忆度：暗灰 = 未读，琥珀亮度越高记得越牢 |
| 渲染 | `react-force-graph-2d` Canvas，自定义 `nodeCanvasObject`（`src/components/graph/GraphCanvas.tsx`） |
| 顶栏 | 品牌「✦ 知识宇宙」、搜索按钮、统计「N 知识点 · M 关系」、fixture 徽标（`GraphTopBar.tsx`） |
| 图例 | 记忆档位色点 + 渐变说明（`GraphLegend.tsx`） |

### 5.3 交互总表

| 交互 | 行为 | 实现 |

### 5.4 详情面板的五个操作

| 操作 | 去向 | 说明 |
|---|---|---|
| 阅读知识 | `/segments/[id]` | 完整阅读并上报停留时长 |
| 开始复习 | `/study/[id]` | 主动回忆 |
| 展开一阶关联 | 视图内聚焦 | 只改视图，不改数据 |
| AI 解释 | `POST /api/ai/explain` | 需配置 LLM |
| 编辑知识点 | `/segments/[id]#edit` | 深链直接进入编辑态 |

### 5.5 空态与降级

- 无数据：展示引导去 `/import` 导入，不显示空白画布。
- 搜索无结果：行内反馈提示（`InlineFeedback`）。
- 加载中：骨架（`Skeleton`），加载完成后才挂载 Canvas。

## 6. 知识库与阅读

### 6.1 知识库列表（`/notes`）

- 搜索框：按标题或标签过滤（`src/app/notes/page.tsx:71`）。
- 每篇文档展示：标题、标签、知识点数、创建时间、平均记忆度灯点。
- 入口：点击进入连续阅读；顶部「导入」进 `/import`。

### 6.2 文档连续阅读（`/notes/[id]`）

- 右侧目录 + 段级记忆灯点，点击跳转对应知识点。
- 支持划线高亮与笔记标注，锚点四元组（quote / occurrence / prefix / suffix）保存。
- 停留时长自动采集：可见时计时，切走/关闭时用 `sendBeacon` 上报（`src/app/notes/[id]/page.tsx:305`）。
- 单次 ≥5 秒记一次有效阅读并推进记忆稳定度；3 分钟全效，单次封顶 10 分钟。

### 6.3 知识点详情（`/segments/[id]`）

| 模块 | 内容 |
|---|---|
| 正文 | Markdown 渲染（`react-markdown` + `remark-gfm`），代码块与表格完整 |
| 记忆 | 当前档位与记忆度、阅读次数、累计阅读时长 |
| 关系 | 出入链（wiki/tag/doc）、共同标签 |
| 操作 | 编辑、删除、移动（上/下）、摘要刷新、划线/笔记 |
| 深链 | 支持 `#edit` 直接进入编辑态（图谱右键菜单使用） |

编辑走 `PATCH /api/segments/[id]`，同一事务内重建 wiki/tag 边并迁移标注。

## 7. 主动回忆（`/study/[segmentId]`）

| 步骤 | 行为 |
|---|---|
| 1. 出题 | `POST /api/learning/question`；无 LLM 或调用失败时降级为原文复述题 |
| 2. 作答 | 只展示问题与作答框，先回忆再看答案 |
| 3. 揭晓 | 点「查看参考答案」（`src/app/study/[segmentId]/page.tsx:209`）展示原文依据的答案 |
| 4. 自评 | 三档：没答出 / 部分掌握 / 答对了（`src/app/study/[segmentId]/page.tsx:30-49`） |
| 5. 调度 | 分别安排 1 / 3 / 7 天后复习，写 `recall_reviews` |

幂等：`submissionId` 唯一约束，网络重试或重复点击只产生一条记录；原文变化后旧题提交返回 409（`sourceVersion` 不匹配）。

## 8. 学习复盘（`/progress`）

- 7 天结论文案：自测数、需巩固数、改善数、活跃天数。
- 14 天学习热力：阅读与自测两类活跃度。
- 与前 7 天对比（`current` / `previous`）。
- 「下一步优先项」：基于薄弱与到期复习给出建议。
- 全部数据读取自流水表实时聚合，无快照表、无定时任务。

## 9. AI 助手（`/ask`）

| 项 | 说明 |
|---|---|
| 常驻上下文 | 知识库概览块（≤600 字）+ 学习者画像块（≤400 字） |
| 工具 | `search_knowledge`、`read_segment`、`propose_actions`，服务端执行，最多 3 轮 |
| 输出 | SSE 流式返回（前端用 `ReadableStream` reader） |
| 改动 | `propose_actions` 只提议不写库；前端确认卡再走 apply 端点 |
| 缓存 | 仅「无工具调用、无改动提议」的直答进 24h 缓存 |
| 深链参数 | 支持 `/ask?segment=…` / `?path=…` 带入上下文 |
| 未配置 LLM | 页面提示去 `/settings` 配置，不发起请求 |

## 10. 导入（`/import`）

| 项 | 说明 |
|---|---|
| 输入方式 | 选择 `.md` 文件，或直接粘贴 Markdown |
| 标题 | 可手填，留空自动取文件名或首个标题 |
| 粒度 | 三档（粗 / 标准 / 细），控制知识点长度上限 |
| 语义拆分 | 可选开关，仅处理超长段（每篇至多 5 段），消耗 token；失败自动保留结构拆分结果，不阻断导入 |
| 自动处理 | 按 `##`/`###`/`####` 标题层级拆解 → 提取 frontmatter 与行内标签、`[[双链]]` → 建 wiki/tag/doc 边 → 原文备份 R2（若配置） |
| 超长处理 | 按句子边界降级组块，不在句中截断；代码块与表格保持完整 |
| 导入结果 | 显示知识点数、语义拆分成功段数 |
| 限制 | 仅 Markdown 纯文本；图片/PDF/DOCX 未实现；Vercel 请求体上限约 4.5MB |

服务端链路：`src/app/api/notes/route.ts` → `splitMarkdown`（`src/lib/splitter.ts`）→ 可选 `semanticSplit` → `db.batch` 原子写文档/段/边。
