# Knowledge Universe · 沉浸式知识宇宙

产品设计方向 v1.0 · 2026-11-04

核心设计理念：让知识不再是一条条等待管理的文本，而成为一个可以进入、探索、连接、学习，并随着理解不断生长的宇宙。

# 二、视觉设计系统：打造真正的知识宇宙

这是本次改造最重要的部分。

我建议采用 深空背景 + 发光知识节点 + 空间层次 + 克制的信息面板 的视觉体系。

但需要避免一种常见失败：所有东西都是黑色背景、蓝紫渐变、玻璃卡片、发光按钮。那样看起来像一个普通的 AI 科技产品皮肤，而不是有独特逻辑的知识宇宙。

一个关键规则：颜色要表达语义，而不是只负责好看。

## 2. 节点设计

我建议节点不再只是一个圆点加文字，而是知识宇宙里的基本视觉对象。

青色标识

节点编码规则

- 大小：关联数量或用户主动设置的重要程度，二者不要混用。
- 亮度：继续表达现有记忆新鲜度。
- 外环：表达掌握证据或特殊状态。
- 颜色：表达当前交互状态或明确的业务语义。
- 标签：默认只展示焦点及附近重要节点，避免满屏文字。

我建议第一版先不做复杂的节点 3D 模型。用 Canvas 2D 也可以通过光晕、粒子、层次和动效做出很好的空间感。节点皮肤作为后续可选主题，而不是一开始就做成复杂的皮肤系统。

## 3. 背景和节点皮肤分离

这两个概念一定要分开设计：

| 个性化对象 | 可调整内容                       | 对产品的影响       |
| ---------- | -------------------------------- | ------------------ |
| 宇宙背景   | 星云、深空、微粒、网格、纯色     | 改变整体氛围       |
| 节点皮肤   | 光球、星体、晶体、环形、简约圆点 | 改变知识节点形态   |
| 关系线     | 细线、能量线、曲线、弱化线       | 改变知识连接的表达 |
| 动效       | 呼吸、脉冲、粒子流、静态         | 改变空间活跃感     |

建议默认提供三种背景：

- Deep Space：极简深空，最适合日常使用。
- Nebula：柔和星云，强调沉浸感。
- Cosmic Grid：空间网格，强调科学探索感。

用户可以切换，但默认只开放少量高质量选择。不要一开始做一个复杂的主题商城。

# 四、功能重设计：让知识宇宙真正有用

视觉是入口，但如果用户每天打开应用，只是看一张漂亮的图谱，产品仍然不会成功。

我建议围绕三个核心循环重新设计功能。

## 1. 探索循环

1. 发现知识

   从图谱、搜索或 AI 推荐进入。

2. 探索关联

   查看相关节点、关系路径和所属主题。

3. 理解知识

   阅读内容，查看解释和相关概念。

4. 形成新连接

   通过学习、标注或确认 AI 建议补充知识关系。

## 2. 学习循环

1. 找到值得学习或复习的知识。
2. 进入知识点，阅读或主动回忆。
3. 记录用户答案和自我评估。
4. 更新学习计划和记忆状态。
5. 在图谱中看到学习产生的变化。

## 3. AI 协作循环

1. 用户选中一个知识点或一组知识。
2. AI 获取相关知识和关系上下文。
3. AI 提出解释、问题或整理建议。
4. 用户确认有价值的操作。
5. 知识库更新，图谱呈现新的关系。

## 4. 最值得新增的三个能力

我认为以下三个功能比增加 PDF、DOCX 等输入格式更值得优先考虑。

A. 知识缺口发现

比如一个知识点关联了多个概念，但用户从未学习过其中的前置知识，AI 可以提示可能的知识缺口。

第一版先做“候选缺口”，让用户确认，不能直接把模型推断当成事实。

B. 知识路径学习

用户选择一个目标知识点，系统展示通往它的相关知识路径，帮助用户按顺序理解。

例如：

```
基础概念 → 核心原理 → 具体应用 → 当前知识
```

路径应基于已有关系和内容，不应凭空生成关系。

C. 知识健康检查

定期发现：

- 孤立知识点。
- 重复或高度相似知识。
- 缺少关联的知识。
- 长期没有回顾的知识。
- 记忆状态和掌握证据不一致的知识。

这些功能可以先生成报告，不需要立刻自动修改数据库。

# 五、设计实现时的技术方案

你现在的技术栈已经有足够的基础，不建议一开始就大规模更换技术。

### 每周的工作时间怎么分配？

- 2 小时：设计、方案审查。
- 5 小时：编码与实现。
- 2 小时：浏览器验收、Bug 修复。
- 1 小时：文档和 Git 整理。

不要让编码占据全部时间。你现在最需要的是方向正确，而不是代码产出速度。

## 每个阶段的验收标准

设计系统阶段

- 首页、图谱、知识详情视觉一致。
- 背景、节点、关系线可以独立调整。
- 文字和状态对比度合格。

图谱阶段

- 搜索结果高亮，其他节点降亮度。
- 选择节点能平滑聚焦。
- 详情面板不遮挡主要操作。
- 路径探索可用。
- 大图性能不能明显低于现有基线。

学习阶段

- 能从图谱直接进入学习。
- 学习后能返回原节点。
- 原有复习提交、幂等和记忆计算不回归。

AI 阶段

- 能获取当前节点上下文。
- 能基于真实关联提供解释。
- 修改必须经过确认。
- AI 不可用时，原有知识库功能仍能正常工作。

# 十、我对这次迭代的最终建议

我想把整个方案再收敛成三个原则：

一个漂亮的知识图谱，如果不能让你更容易发现知识、理解知识、记住知识，它就只是一个漂亮的图谱。
