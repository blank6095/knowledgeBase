## 2. 高优先级实施计划

### H1/H4 · 今日学习与确定性推荐

- **修改范围**：`src/lib/learning-plan.ts`、`src/app/api/learning/today/route.ts`、首页面板。
- **规则**：上次未答出 → 已到期复习 → 最近读过但无自测 → 未读/兜底；每类内部按固定字段排序。
- **预期效果**：打开首页即可看到 3 条带原因的学习项目，不需要 LLM 排序。
- **验收**：固定时间/固定数据下顺序可重复；重复知识去重；无历史与空库均有降级。

### H2/H5 · 主动回忆与来源一致性

- **修改范围**：`recall_reviews` 表、`/api/learning/question`、`/api/learning/reviews`、`/study/[segmentId]`。
- **约束**：回答前不展示参考答案；问题与引用只基于当前知识段；内容版本变化则拒绝旧题提交。
- **预期效果**：首页进入后完成“看题 → 作答 → 揭晓答案 → 记录结果 → 回原文”。
- **验收**：刷新后记录仍在；重复 `submissionId` 不产生重复行；空答案只允许“没答出”；非法来源返回 4xx。

### H3 · 复习记录与调度

- **修改范围**：Drizzle schema、0007 迁移、复习 API。
- **调度**：没答出 +1 天；部分掌握 +3 天；答对 +7 天。
- **预期效果**：复习事实与阅读记忆度分离，下一次推荐可依据作答结果。
- **验收**：同一知识多次复习有独立记录；删除知识时记录级联清理；原有 stability/readingMs 不受影响。

### H6 · 回归与文档

- **修改范围**：Vitest、Playwright、README、spec、未完成任务清单、本报告。
- **预期效果**：核心排序、调度、版本校验、幂等和浏览器主流程均有自动化覆盖。
- **验收**：`npm test`、`npm run lint`、`npm run typecheck`、`npm run build`、`npm run test:e2e` 全部通过。

## 3. 分阶段执行顺序

1. 数据契约与迁移：复习记录、索引、调度纯函数。
2. 核心服务：内容版本、题目生成、复习写入、今日推荐。
3. 主界面：首页今日学习、回忆页、来源回看、轻量周反馈。
4. 回归：单测、API 幂等/边界、E2E、真实数据库清理验证。
5. 文档收尾：任务清单、spec、README、项目上下文与本报告同步。

## 4. 暂不实施

图谱规模化、更多导入格式、向量检索、新 Agent 工具、复杂统计、多用户和全站重构不在本轮范围。任何安全或数据完整性阻断问题若在实现中出现，优先级高于上述暂缓项。

## 5. 交付结果

### 5.1 核心闭环

- 首页 `TodayLearningPanel` 展示 3 条推荐、原因与近 7 天反馈。
- `/study/[segmentId]` 完成“问题 → 作答 → 参考答案 → 结果记录 → 原文回看”。
- 新增 `recall_reviews` 表与 0007 迁移；独立于 `reading_events` 和记忆度。
- 调度规则：没答出 +1 天、部分掌握 +3 天、答对 +7 天。
- 未来已排期内容不会为了凑满 3 条而提前出现。

### 5.2 边界与可靠性

- `sourceVersion = sha256(title + content)`；原文变化返回 409。
- `submissionId` 唯一索引与 `onConflictDoNothing` 双重保护重复提交。
- 无 LLM 或出题失败时退回原文复述题，不阻断学习。
- ask 缓存只覆盖无工具、无改动提议的直接回答，24h TTL。

### 5.3 验证证据

- Vitest：28 个测试文件、184 个用例通过。
- Playwright：6 个浏览器用例通过，覆盖登录、图谱、主动回忆、AI 解释和学习复盘。
- 真实 Neon：迁移成功；真实出题、复习提交、重复提交、周反馈状态验证通过；测试记录已清理为 0。
- `npm run lint`、`npm run typecheck`、`npm run build` 全部通过。
- `npm run db:migrate:check`：数据库已是最新。
