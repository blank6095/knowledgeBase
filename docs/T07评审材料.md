### 移动端真实触控补充验收

**目的：** 验证移动端不是桌面布局的简单缩小，并确认底部 Sheet 展开后主要操作仍然可用。

**风险判断（采纳评审意见）**：紧凑星图的可读性可由截图与视口测试较容易发现；Sheet 与图谱之间的**触控隔离**——遮挡、点击穿透、滚动冲突、关闭后上下文丢失、底部安全区——单靠截图与几何数据基本无法证明，列为**高风险、重点检查**。

| 检查项 | 紧凑星图可读性 | 底部 Sheet 展开后的主操作 |
|---|---|---|
| 现有截图能否发现 | 较容易 | 很难 |
| 几何测试能否发现 | 部分可以 | 基本不能 |
| 真实触控必要性 | 建议 | **强烈建议** |
| 典型风险 | 节点太密、标签不可辨认、目标难以定位 | 遮挡、点击穿透、滚动冲突、关闭后状态丢失、安全区遮挡 |
| 风险等级 | 中等 | **高** |

**检查范围：**

1. 紧凑星图的节点与关系可读性。
2. Sheet 展开、滚动、关闭及底层交互隔离。
3. 主要操作入口的触控可达性。
4. 关闭 Sheet 后图谱位置及交互上下文恢复。
5. 底部安全区域适配。

**完整操作链（比逐项点按钮更有价值）**：进入图谱 → 搜索 → 选中节点 → 展开 Sheet → 执行操作 → 关闭 Sheet → 恢复图谱探索。目标视口：320 / 375 / 390。

> **进度**：模拟触控 **8/8**（三视口共 **24/24**）；**真机 0/8**。模拟结果不得当作真机通过记录。

**模拟触控预检结果（2026-11-07，Playwright `hasTouch` + CDP touch 事件，非真实设备）**

- 脚本：`prototypes/knowledge-universe/touch-walkthrough.mjs`；数据：`screenshots/touch-walkthrough.json` / `.md`；连续截图：`screenshots/touch-*.png`。
- 首轮：**12/24 通过**。发现 4 类阻断问题，全部落在 Sheet 高风险区：
  1. 移动端 Sheet 高达视口 **64–83%**（320px 下 83%），底层图谱与主操作几乎不可见；
  2. 手指在 Sheet 上滑动导致**页面跟随滚动 401–451px**（`overscroll: auto`、body 未锁滚动），连锁造成后续「询问 AI」与路径第二个节点点空；
  3. 「阅读 / 主动回忆 / 询问 AI」落在需滚动才能看到的区域，**看得见却点不到**；底层搜索 / 模式栏 / 导航被遮罩隔离且无等价入口；
  4. 320px 下 toast 提示条**拦截了节点 tap**；紧凑星图在搜索降权时焦点标签被隐藏。
- **处理结果（仅修原型）**：移动端 Sheet 默认半屏 `55dvh`、可切换 `92dvh`；`overscroll-behavior: contain` + `body.sheet-open` 锁页面滚动；Sheet 顶部工具行提供「继续搜索 / 返回图谱」等价入口，主操作区提到工具行之后免滚动可达；`.toast { pointer-events: none }`；搜索降权时保留焦点标签。
