**测量方法定稿（T01 交付，T10 / T24 复用，不得中途改标准）**

| 项 | 规则 |
|---|---|
| 预热 | 每轮先以同一登录态打开一次 `/graph?fixture=graph-small` 完成模块预热并关闭页面；正式测量的首帧不计入采样（脚本的 4s rAF 窗口从首 tick 之后开始，与之兼容） |
| 重复次数 | **每档 fixture 连续测 3 次**，三档共 9 次为一组完整基线；异常值不丢弃：若某次 FPS 与三次中位数偏差 >20%，追加第 4 次，取 4 次的中位数，并在报告中保留全部原始值 |
| 取值规则 | FPS / 耗时指标一律取**中位数**，并同时记录最小–最大波动范围；长任务记录**次数**与最大耗时；P95 帧耗时取每次采样内的 P95 后取中位数 |
| 允许回归阈值 | 相对 T01 同条件基线：① FPS 中位数下降 **≤10%**；② `firstTickMs` 增加 **≤10%**；③ `engineStopMs` 增加 **≤10%**；④ `zoomProbe.twoWorstFramesMs` 增加 **≤15%**；⑤ 长任务次数**不增加**、最大耗时增加 **≤10%**；⑥ 帧耗时 P95 仅记录，不作阻塞项 |
| 失败处置 | 任一阻塞项超阈值即判定回归，T10 不得验收通过；**不得通过放宽阈值、删档位或跳过用例来通过验收**（执行版 T24 禁止项） |
| 执行保护 | 脚本会覆盖 `artifacts/graph-baseline.json`（既有未提交改动）。重测前必须先备份该文件，并把新结果写入独立报告文件，不覆盖既有文件 |
