# 「知识宇宙」系统优化方案

> 版本 v1.0 · 2026-11-01 · 状态：待评审实施
> 基准：Obsidian / Logseq / Notion 的核心理念（本地优先、纯文本可迁移、双向链接、快速切换、渐进式披露）
> 事实来源：本仓库代码与既有文档（行号为 2026-11-01 核实状态），已落地的能力不再立项。

---

## 1. 设计原则（用于取舍，不是口号）

| 原则 | 含义 | 对本项目的约束 |
|---|---|---|
| **本地优先** | 数据主权在用户手里 | 保留单用户口令 + Neon/R2 现状，但**必须补齐一键导出**；不做"只进不出" |
| **链接即组织** | 分类靠关联而非目录树 | 优先做双链与反向链接，标签只做辅助，不引入复杂目录/层级体系 |
| **渐进式披露** | 新手只看主线，高级能力收在面板里 | 图谱默认形态简单（隐藏孤立点、不显示力参数），高级项收进"显示/力/主题" |
| **纯文本可迁移** | 知识以 Markdown 存在 | 导出格式必须是 Markdown + frontmatter，而非私有 JSON |
| **AI 是助手不是作者** | AI 只提议，人确认 | 维持现有 preview → apply 两步；AI 产物永不直接写库 |

## 2. 现状基线（已完成能力不重复投入）

| 维度 | 已有 | 主要缺口 |
|---|---|---|
| 采集 | `/import` Markdown/粘贴 + 启发式拆分 + LLM 语义拆解/聚合（preview→apply）+ R2 原文备份 | 无 PDF/DOCX/网页剪藏（C2 挂起）、无附件（C3 挂起）、无"新建空白知识点"入口 |
| 分类 | 段/文档标签（`#tag` 提取）、共同标签边、图谱分组染色 | 无标签聚合页、无按标签筛选图谱、无嵌套/层级标签 |
| 双向关联 | `links(wiki/tag/doc)`、段详情出链/入链/共同标签组、最短路径 + AI 解释 | **阅读视图不渲染 `[[内链]]`**、**断链被静默丢弃**、无未链接提及、同名 `[[标题]]` 歧义 |
| 图谱 | KnowledgeUniverse 全套（搜索、局部探索、学习地图、主题、小地图、簇锚点、碰撞、固定预布局、孤立点隐藏、同名消歧） | 跨文档主题聚类、枢纽/索引型知识点、孤立点清单 |
| 检索 | 图谱内 Ctrl+K 多字段评分、ask 内部 `retrieveByQuery` | **全站无全局检索入口**，`/notes` 仅前端 title/tag 过滤、无内容命中片段 |
| 回顾 | 今日学习（`/study` 主动回忆 + AI 出题）、周报复盘热力、记忆度衰减 `exp(-Δt/S)`、薄弱优先 | 复习入口分散、没有"未掌握/已掌握"的知识点列表视图、缺"段落级间隔重复"的可见规则说明 |
| 沉淀 | 划线/笔记批注、灯点摘要卡、阅读时长与次数 | **无导出/备份**、无"我的笔记"独立视图、批注不参与检索 |
| 隐私 | 单用户口令 + 会话 Cookie、CSP、API Key AES-GCM | 云库存储（Neon/R2）缺"数据在哪个国家/如何删除"说明；密钥轮换成本高 |

## 3. 痛点 → 优化目标（按用户旅程）

1. **"我导入了很多，但找不到那段话"** → 全局检索（标题 + 标签 + 摘要 + 正文）+ 内容命中片段，首击可达。
2. **"我写了 `[[...]]`，阅读时却点不了"** → 阅读视图内联双链可点击，断链可见、可一键创建，形成"边读边织网"。
3. **"图谱好看但看不出主题"** → 跨文档主题聚类 + 按标签筛选/着色 + 索引型（MOC）知识点，让图能回答"这个领域我有什么"。
4. **"记得不牢、也不知道复习什么"** → 复习闭环从"今日推荐"升级为"到期 + 薄弱 + 未读"三档清单，规则透明、可跳过重排。
5. **"万一我想搬走呢"** → 一键导出全部（Markdown + 关系 + 批注 + 复习记录），删除账号可彻底清理。

## 4. 核心功能改进（按维度）

### 4.1 采集：从"只能导入"到"随处可写"

- **新建空白知识点**：允许不依附文档建段（现 `/api/notes/[id]/segments` 必须带 documentId）。新增"快速记录"入口（全局 `N` 快捷键 / 导航 "+"），支持只写一句 + 可选 `[[链接]]`。产出：`POST /api/segments`（documentId 可空，或落入"收件箱"文档）。
- **采集分层**：粘贴/文件（已有）→ 网页剪藏（P1）→ PDF/DOCX（P2，依赖授权）。附件（图片/音频）统一 P2，跟随 C3 决策。
- **导入质量反馈**：导入后展示"段数 / 标签数 / 双链数 / 孤立段数"，而不是只跳成功页，让"采集是否有效"可度量。

### 4.2 分类：标签做"横向索引"，不做目录

- **标签聚合页 `/tags`**：列出全部标签及段数，点进去看"该标签下所有段"（一条 group by SQL）。
- **图谱按标签筛选/着色**：`buildGraphData` 增 `tagOn`（数据已在节点 `tags` 字段），面板里多选标签即收敛视野。
- **同名歧义治理**：`[[标题]]` 解析顺序 = 同文档 > 唯一匹配 > 多匹配时提示选择（不再静默连全部）。

### 4.3 双向关联：链接回到正文

- **阅读视图渲染 `[[内链]]`**：自写 remark 插件（零新增依赖）把 `[[title]]` 转为 `next/link`；悬停出摘要卡（复用 `/api/segments/[id]`）。
- **断链可见**：`links.ts` 增加"未解析 `[[target]]`"收集 SQL，阅读页灰虚线显示，点击一键创建该知识点。
- **未链接提及**（P2）：段正文提到标题但未写成 `[[...]]` 时提示，批量转为双链。
- **关系语义分层**：UI 明确区分"我写的链接（wiki）/ 同主题（tag）/ 同文档顺序（doc）"，避免把结构边误认为关联（当前 doc 边占大头）。

### 4.4 图谱可视化：从"看形状"到"找结构"

- **跨文档主题聚类**：在 doc 分簇之上叠加"标签传播社区检测"，让同主题跨文档也能聚在一起（P1，纯函数可单测）。
- **枢纽层**：度数 Top 节点常显标签 + 「以此为索引」创建 MOC（连接 4.1 的空白建段）。
- **孤立点清单**：隐藏的孤立段可在面板展开，支持批量补链，而不是只藏起来。
- **保留既有**：搜索四态、局部一/二阶探索、最短路径、学习地图、主题、小地图、聚焦一阶高亮、直线边、固定预布局。

### 4.5 检索：一个入口找全部

- **全局 QuickSwitcher**（全站 `Ctrl/Cmd+K`）：图谱内的 `graph-search.ts` 评分逻辑上移为共享索引，支持"标题 / 标签 / 摘要 / 正文"四类命中；`Ctrl+Shift+K` 打开全文检索。
- **内容命中片段**：新增 `/api/search`（服务端 ILIKE + 复用 `tokenize` 分词），返回 2 行上下文片段与跳转定位。
- **批注入检索**：自己的划线/笔记也可被搜到（个人知识资产）。

### 4.6 回顾：让复习规则可见、可控

- **三档清单**：到期（nextReviewAt <= now）/ 薄弱（memory<0.4）/ 未读，替换单一"今日推荐"。
- **复习规则透明**：在 `/study` 页显示"为什么是它 + 下次何时再见"，允许"跳过/延后"。
- **知识点列表视图**：`/notes` 或新增 `/library` 支持按"未读/薄弱/已掌握"筛选与排序，让回顾不止发生在图谱。

### 4.7 沉淀与可迁移

- **一键导出**：`/api/export` 产出 zip（`notes/*.md`（含 frontmatter：tags/memory/review）+ `links.json` + `annotations.json` + `profile.json`）。原文优先取 R2 `storageKey`，无则按段重建 Markdown。
- **我的笔记视图**：批注（划线/想法）独立列表，支持按文档/时间回看——这是"沉淀"的实体。
- **隐私说明与删除**：设置页明确数据存放（Neon 区域、R2 桶、LLM 提供方）与"删除我的数据"入口（级联删除 segments/links/annotations/reviews/R2 对象）。

## 5. 交互设计：两条路径

| 路径 | 设计 |
|---|---|
| **新手** | 首屏只有三件事：导入、今日学习、搜索。图谱默认隐藏孤立点与高级面板；阅读页内链直接可点；看到断链可一键创建。**全程不需要懂"双向链接"概念。** |
| **深度用户** | 图谱"显示/力/主题/地图"面板、快捷键（`Ctrl+K` 检索、`N` 新建、`G` 回图谱）、标签筛选、MOC 创建、导出、LLM 拆解/聚合。全部渐进式展开，不占主路径。 |

## 6. 实施阶段（按优先级）

### 阶段 P0 · 关联闭环与全局检索（约 5–7 人日）

| 内容 | 预期价值 | 衡量指标 | 主要风险 |
|---|---|---|---|
| 阅读视图 `[[内链]]` 渲染 + 断链可见可建 **（渲染与断链可见已交付 2026-11-01；"一键创建"待 P1 空白建段）** | 双链从"写在库里"变成"读时可用"，关联成本骤降 | 内链点击率 ≥15%；断链创建转化 ≥20% | 渲染/锚点与既有批注高亮冲突 → 括号用字号 0 隐藏，保 textContent 不变（已实现） |
| 全局 QuickSwitcher（**标题/标签/路径/摘要已交付 2026-11-01**；正文命中片段待服务端 `/api/search`） | 找段落不再靠翻页或问 AI | 首击成功率 ≥70%；搜索耗时 <300ms（500 段） | 服务端 ILIKE 在大库变慢 → 先 ILIKE，>5k 段再评估 pg_trgm |
| 标签聚合页 + 图谱按标签筛选 | 主题视野可收敛 | 标签筛选后相关段命中率 ≥80% | 标签过多面板臃肿 → 默认按使用频次 Top 30 |

**出口门禁**：`npm test`、`typecheck`、`lint`、`build`、`npm run test:e2e` 全绿；1440/375 实拍；真实库手动验证一次"读到一半顺链跳走"。

### 阶段 P1 · 采集与主题结构（约 5–8 人日）

| 内容 | 预期价值 | 衡量指标 | 主要风险 |
|---|---|---|---|
| 新建空白知识点 + 快速记录入口 | 可从零写笔记/MOC，不再依赖导入 | 空白建段周使用 ≥3 次 | 数据模型 documentId 可空需迁移与回退脚本 |
| 跨文档主题聚类 + 枢纽/MOC | 图能回答"这个领域我有什么" | 同主题跨簇误判率下降；MOC 点击后到达率 | 标签传播可能产出巨社区 → 设规模上限并回退 doc 分簇 |
| 网页剪藏（单格式） | 采集覆盖日常来源 | 剪藏成功率 ≥85% | 解析依赖与正文质量 → 先做只读 HTML，不接登录态站点 |
| 导入质量反馈 | 采集有效性可度量 | 导入后孤立段占比 <20% | 指标口径需统一（与图谱孤立点一致） |

### 阶段 P2 · 回顾与沉淀（约 4–6 人日）

| 内容 | 预期价值 | 衡量指标 | 主要风险 |
|---|---|---|---|
| 三档复习清单 + 规则透明 | 复习可解释、可控制 | 到期复习完成率 ≥60%；7 日留存复习次数 | 推荐口径变化影响既有用户习惯 → 保留"今日推荐"为默认视图 |
| 我的笔记/批注独立视图 | 个人想法可回看、可检索 | 批注周回看 ≥2 次 | 批注与段版本失配 → 沿用现有失效锚点提示 |
| 未链接提及（库 >500 段启用） | 自动补全关联 | 提议采纳率 ≥30% | 误报率 → 阈值与确认列表 |

### 阶段 P3 · 可迁移与扩展（约 3–5 人日）

| 内容 | 预期价值 | 衡量指标 | 主要风险 |
|---|---|---|---|
| 一键导出（Markdown + links + annotations） | 数据主权与迁移自由 | 导出 <5s/500 段；再导入还原度 ≥95% | 段/关系版本兼容 → 导出带 schemaVersion |
| 隐私说明 + 数据删除 | 合规与信任 | 一键删除后 DB/R2 无残留 | 级联遗漏 → 写删除集成测试 |
| PDF/DOCX、附件（按需） | 采集扩展 | 按实际使用频率决定 | 依赖体积与解析质量 |

## 7. 衡量指标总表

| 目标 | 指标 | 采集方式 |
|---|---|---|
| 找得到 | 检索首击成功率、平均检索耗时 | 前端埋点（仅记维度，不记内容） |
| 连得上 | 内链点击率、断链创建数、孤立段占比 | `links` 表与前端事件 |
| 看得懂 | 图谱筛选使用率、MOC 到达率 | 前端事件 |
| 记得住 | 到期复习完成率、memory<0.4 段占比周变化 | `recall_reviews`、`segments` |
| 搬得走 | 导出耗时、再导入还原度 | 导出接口日志 |

## 8. 主要风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 功能膨胀压垮新手 | 主路径被面板淹没 | 渐进式披露；默认隐藏孤立点/高级面板；新手路径单独走查 |
| LLM 成本与配额 | 拆解/出题/解释频繁调用 | 沿用 `llm_calls` 观测与日 token 护栏；缓存指纹复用；新功能默认不自动调 LLM |
| 云库隐私 | Neon/R2 第三方存储 | 设置页明示区域与提供方；提供导出与删除；API Key 继续 AES-GCM，不新增明文存储 |
| 大图性能 | >5k 段布局/检索变慢 | 固定预布局 + 规模分档；检索先 ILIKE 后评估 pg_trgm；社区检测设上限 |
| 数据模型变更 | documentId 可空、导出格式演进 | 迁移脚本 + schemaVersion + 回退方案 |

## 9. 明确不做（本期）

- 多人协作/共享空间/评论（单用户定位）
- 引入向量检索/pgvector（A3 条件未触发：当前抽样不足）
- WebGL/WASM 图谱渲染（D2 决策项，现有 Canvas 足够）
- 复杂目录树/层级标签（与"链接即组织"冲突）
- 全量替换为 Obsidian 插件生态（保持现有 Next.js + Drizzle 架构）

---

**一句话路线**：先把"链接在正文里可用、全站能搜到"补齐（P0），再让"能随手写、按主题看"成立（P1），随后把"复习与沉淀"做透明（P2），最后交付"搬得走、删得净"（P3）。每一步都不推翻现有架构与已交付的图谱能力。
