# Knowledge Universe · 第一轮高保真原型（T04–T06）

> 独立静态原型，对应 [执行版任务清单.md](../../执行版任务清单.md) v1.2 · 冻结版 T04 / T05 / T06。
> 按 §4「原型交付统一约定」：独立静态页面、模拟数据、不新增依赖、不接真实数据库与业务 API、**不进入 Next.js 业务路由**。

## 1. 启动与访问

无需安装、无需构建、无需服务：

```
直接用浏览器打开 index.html（file:// 即可）
```

也可用任意静态服务托管本目录（例如 `python -m http.server`），入口同为 `index.html`。三页之间为相对路径跳转，`file://` 下同样可用。

**不执行 `npm run build`**：原型不在构建链路内（执行版 §4 明确）。

| 桌面 | 1440×900 |
| 移动 | 390×844 / 375×667 / 320×720 |

产出 **36 张截图**（`capture.mjs` 28 张 + `touch-walkthrough.mjs` 8 张）：

- 12 张基础整页截图：`{page}-{viewport}.png`
- 9 张三态截图：`{page}-state-{empty|loading|error}.png`（桌面）
- 4 张交互态截图：`graph-state-{search|detail|ai|path}.png`
- 3 张真实首屏视口图：`{page}-viewport-390x844.png`（`fullPage: false`，保留固定底栏）
- 8 张移动端触控链路连续截图：`touch-{viewport}-{step}.png`
- `screenshots/geometry.json` / `geometry.md`、`touch-walkthrough.json` / `.md`：几何与触控走查数据

**截图规则**：整页全貌图仅在截图时把固定底栏由 `fixed` 归位为页面底部的 `absolute`，避免 Playwright `fullPage` 拼接时 fixed 元素落在页面中部、看似压盖内容；该规则不改变任何尺寸、间距或布局逻辑。真实首屏图未做任何调整，用于核对底栏位置与遮挡。

几何检查对象为 `button` / `input` / 底部导航项 / 抽屉项 / 浮层操作 / SVG 节点热区；**正文中的内联文本链接按 WCAG 2.2 · 2.5.8 的 Inline 例外不计入 44px 目标尺寸**。

**实测结果**：12 组（3 页 × 4 视口）全部 0 横向溢出、0 个触控目标 <44px、0 个页面脚本错误。

## 5.1 移动端触控走查（T07 补充验收预检）

```
node touch-walkthrough.mjs
```

在 320×720 / 375×667 / 390×844 三个触屏视口（`hasTouch` + CDP touch 事件）跑完整链路：进入图谱 → 搜索 → 选中节点 → 展开 Sheet → 执行操作 → 关闭 Sheet → 恢复图谱探索，输出 8 项检查 × 3 视口的结果与连续截图 `touch-*.png`。

**Sheet 行为**：移动端默认半屏 `55dvh`，可用「展开全屏」切至 `92dvh`；`overscroll-behavior: contain` + `body.sheet-open` 锁页面滚动；顶部工具行提供「继续搜索 / 返回图谱」等价入口，主操作区提到工具行之后免滚动可达；`.toast` 不接收指针事件。底层搜索 / 模式栏 / 导航在 Sheet 展开时按 modal 语义隔离，防止误触底层节点。

> **边界**：这是**模拟触控，不是真机走查**。iOS 动态工具栏、安全区真实取值、系统返回手势、滚动惯性、长按与触觉反馈、横竖屏切换均无法覆盖。真机部分须人工完成并记录到 [T07评审材料.md](../../T07评审材料.md) 的「移动端真实触控补充验收」小节。当前模拟触控 **24/24 通过**，真机 **0/8 待执行**。
