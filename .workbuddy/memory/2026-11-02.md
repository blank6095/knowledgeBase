## 移动端屏幕适配（知识宇宙页，2026-11-02）

- 用户截图现象：手机端 `/graph` 只有顶栏 + 骨架屏 + 底部导航，画布空白。定位为 `nodes === null` 的加载态——`/api/graph` 在移动网络下慢/挂起，页面没有超时与出口（错误态只在 fetch reject 时出现）。
- 审计工具：新增 `artifacts/mobile-audit.mjs`（320/360/390/412/768/844 横屏/1440，量 overflowX、浮层越界、底部导航条目重叠、设置面板与导航遮挡、截图）。基线数据存 `artifacts/mobile-before3|final/report.json`。
- 实测根因：底部导航 7 个 `h-11 w-11 shrink-0` 按钮在 320px 下 **相邻重叠 5px**（gap -5），390px 以下逐渐相切。桌面左栏不受影响。
- 修复：GraphNavigation 移动端按钮改 `w-full min-w-0`（等分槽位），`md:w-11` 恢复桌面固定 44；ul `gap-0 sm:gap-0.5`；退出块 `w-10 md:w-full`。320px 下每格 40px、零重叠、lastRight ≤ 容器内边界。
- 修复：设置面板 `max-h-[calc(100dvh-9rem)]` → 移动端 `-13rem`（md 保持 9rem）。旧值在长内容 tab（地图/显示）会把底部 52px 藏进底部导航。
- 修复：加载态加 10s 慢网提示 + 「重新加载」；错误态从裸 `<p>` 改为居中卡片，带「重新加载 / 返回知识库」两个出口。
- 触屏命中：`nodePointerAreaPaint` 收到 globalScale，粗指针设备（`(pointer: coarse)`）命中半径抬到 ≥12 屏幕 px（直径 24px）；鼠标端不变。
- 否决：加「适应视图」按钮——实测 360px 下 zoomToFit 得 0.09 倍，2712 单位图谱压成中间一小团，可读性反而更差。
- 验收：`artifacts/graph-load-state-verify.mjs`（错误/重试/慢网三路径）；mobile-audit 320–412 零溢出零重叠；1440 桌面导航与动作簇坐标与改前一致；typecheck / 400 单测 / lint 0 error / build / e2e 6-6。
- 环境坑：`.next` 若由 `next build` 生成，`next dev` 启动时批量删除会触发 safe-delete 保护（SAFE_DELETE_BULK_CONFIRM_REQUIRED）；e2e 冷启动登录页编译 6.5s > 5s 断言超时，先手动预热 3100 后 6/6。

## /graph 移动端 UI 重构（feature/graph-ui 分支）
- 分支：从 master 新建 `feature/graph-ui`（仓库原本没有该分支）。
- Header：<md 隐藏「知识宇宙」Logo（GraphTopBar `hidden md:flex`），搜索占满剩余宽度；顶栏加 `pt-safe`。
- 动作簇：≥md 三个按钮直排；<md 收成一个「更多操作」下拉（学习地图/联系两概念/图谱设置），带 aria-haspopup + Esc/点外关闭。
- 底部导航：GraphNavigation 新增 `compactOnMobile`（仅 /graph 传），<md 只渲染 universe/library/assistant + 「更多」抽屉；抽屉含全部入口 + 退出，`pb-[max(0.75rem,env(safe-area-inset-bottom))]`。
- 图例：<md 折叠为 44×44 渐变圆点，点击展开原 220px 面板；`bottom-[calc(5rem+env(safe-area-inset-bottom))]`。
- Canvas：布局收敛后首屏 fitGraphView —— 视口够用调 `zoomToFit(420, padding)`，装不下（fit < 0.2）则 `zoom(0.2)+centerAt`；触屏节点视觉半径 ≥2.6 屏幕 px；触屏标签阈值 ×0.55（1.2→0.66）、字号 11px；新增标签矩形占位剔除（每帧重置，触屏上限 45 条）。
- 视口：layout.tsx 加 `viewportFit: 'cover'`，globals.css 加 `@utility pt-safe / pb-safe / bottom-safe-3`；非沉浸页 AppShell 加 pt-safe + 左右安全区。
- 验收：artifacts/graph-ui-verify.mjs（dev/start 两种模式）四视口数据全绿（375/390 zoom 0.2、logo 隐藏、nav 4 项、legend 44；768/1440 logo 显示、三按钮、nav 7）；截图在 artifacts/graph-ui/。
- 门禁：typecheck / 400 单测 / lint 0 error / npm run build / e2e 6-6。
- 坑：`(. cmd &)` 起的 dev 服务器会随父 shell 退出；e2e 要用 Bash run_in_background 起服务并先预热 /login，否则 5s 断言超时。
