## Obsidian 六图诊断与图谱质量治理（2026-11-01）
- 截图结论：外围 100+ 孤立点（png 附件为主）、同名节点重复（React-MOC×2/Redux×2/03.Layout模块×4）、附件入图、MOC 单点 40+ 辐射缺层次、同主题跨簇分散、同对多边冗余。对我们的映射：孤立段、同名段+[[标题]]歧义、三线并存、无 MOC 层、文档分簇忽略跨文档主题。
- 落地：buildGraphData 增加 options（hideOrphans 默认 true / dedupeLinks 默认 false / pinInitial true）；buildDisplayLabels 同名加文档后缀；nodeRadiusFor 统一绘制/命中/碰撞半径；unpinAll 解冻。
- 布局结论（重要）：长链 + 跨簇边会让自由力导向把聚合预布局改写成放射长臂，调 charge/alphaDecay/doc 强度均无效；最终用 fx/fy 固定预布局（pinInitial），拖拽后重新 pin，调参与「重新布局」解冻。
- 坑：Graph 动态挂载 → 力必须在 onEngineReady 注册；d3Force 的 link accessor 会被 graphData 更新覆盖，需 120ms 后补挂；React lint 禁止渲染期写 ref 与直接 delete 节点 fx/fy（改用 unpinAll 纯函数置 null）。
